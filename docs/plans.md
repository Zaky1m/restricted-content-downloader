# Plans and points

**English** · [العربية](plans.ar.md)

| | Free | Premium |
|---|---|---|
| Downloads per day | 25, plus gift and referral points | No limit |
| Open tasks | 1 | 5, run one after another |
| Running tasks | Four slots shared by all free users | Not limited by other users |
| Copy a channel, watch a channel | No | Yes |
| Files above 2 GB | Split into parts | Parts, or whole through a linked Premium account |

## Premium

Premium is paid in the bot with Telegram Stars:

- 30 days for 200 Stars
- 365 days for 2000 Stars

Paid days are added to the time left. Admins can also grant Premium for 1, 3,
7, 30, 90 or 365 days, or any number of days.

## Points

A single link costs one point, an album included. A range costs one point per
post in it. Points are spent in this order:

1. The daily allowance, which resets every day
2. Gift points, the ones that expire soonest first
3. Referral points

## Referrals

Every user has a link of the form `https://t.me/<bot>?start=<user id>`. When a
new user starts the bot through it and answers a short sum question, the
inviter gets 200 points and the new user 50. When the inviter is Premium they
get 400 and the new user 200.

## Gifts

Admins create gift links that add points. A gift can expire, limit how many
users claim it, or be meant for chosen users only. Each user claims a gift
once.
